### Identity Map Pattern Specific Considerations

- **Single Instance Per ID**: Ensure same object instance returned for same ID
- **Reference Equality**: obj1 = obj2 when loaded with same ID
- **Cache Storage**: Use %ArrayOfObjects or multidimensional property
- **Lazy Loading**: GetOrLoad pattern loads only if not cached
- **Cache Invalidation**: Remove or update on object changes
- **Scope Management**: Session-level, request-level, or transaction-level
- **Statistics Tracking**: Monitor hits, misses, cache size
- **Memory Management**: Clear cache at appropriate boundaries
- **Thread Safety**: Consider concurrent access patterns
- **Integration**: Works with Data Mapper and Unit of Work patterns

### Identity Map Implementation Patterns

[Source: architecture/coding-standards.md]

**Add Pattern:**
```objectscript
Method Add(pId As %String, pObject As %RegisteredObject) As %Status
{
    Set tSC = $$$OK
    
    Try {
        // Store in map
        Do ..Cache.SetAt(pObject, pId)
        
        // Update statistics
        Set ..Size = ..Size + 1
        
    } Catch ex {
        Set tSC = ex.AsStatus()
    }
    
    Quit tSC
}
```

**Get Pattern:**
```objectscript
Method Get(pId As %String) As %RegisteredObject
{
    Set tObject = ""
    
    Try {
        // Check if exists
        If ..Cache.IsDefined(pId) {
            Set tObject = ..Cache.GetAt(pId)
            
            // Update hit count
            Set ..HitCount = ..HitCount + 1
        } Else {
            // Update miss count
            Set ..MissCount = ..MissCount + 1
        }
        
    } Catch ex {
        // Log error
    }
    
    Quit tObject
}
```

**GetOrLoad Pattern:**
```objectscript
Method GetOrLoad(pId As %String, pLoader As %String) As %RegisteredObject
{
    Set tObject = ""
    
    Try {
        // Check cache first
        Set tObject = ..Get(pId)
        
        // If not in cache, load it
        If '$IsObject(tObject) {
            // Call loader method
            Set tObject = $CLASSMETHOD(pLoader, "Load", pId)
            
            // Add to cache if loaded successfully
            If $IsObject(tObject) {
                Do ..Add(pId, tObject)
            }
        }
        
    } Catch ex {
        // Log error
    }
    
    Quit tObject
}
```

**Medium Risks**:
1. **Cache Eviction Algorithm** (Probability: Medium, Impact: Medium)
   - Current: FIFO using Cache.Next() may not evict optimal entries
   - Risk: Frequently accessed objects evicted instead of cold ones
   - Mitigation: Acceptable for initial implementation, consider LRU in future
   - Monitoring: Track hit ratio to detect poor eviction performance

2. **Memory Consumption** (Probability: Medium, Impact: Medium)

   - Risk: Debugging difficulties in production

2. **Thread Safety** (Probability: Low, Impact: Low)
   - No explicit locking for concurrent access
   - Risk: Race conditions in multi-threaded scenarios
   - Mitigation: IRIS sessions typically single-threaded, document limitation
