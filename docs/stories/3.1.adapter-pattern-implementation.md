### Naming Conventions
[Source: architecture/coding-standards.md]
- Classes: PascalCase (Adapter, ClassAdapter, ObjectAdapter)
- Methods: PascalCase for public (Request(), SpecificRequest())
- Properties: PascalCase (AdapteeInstance)
- Parameters: Prefix with 'p' (pAdaptee, pRequest)
- Local variables: Prefix with 't' (tResult, tAdapter)

### Class Structure Template
[Source: architecture/coding-standards.md]
```objectscript
/// Gang of Four Adapter Pattern - Target Interface
Class Patterns.GoF.Structural.Target Extends %RegisteredObject [ Abstract ]
{
    /// Standard request method
    Method Request() As %String [ Abstract ]
    {
        Quit ""
    }
}
```

### ObjectScript-Specific Considerations
- Multiple inheritance limitations: ObjectScript doesn't support true multiple inheritance, so class adapter must use workarounds
- Use %Extends for single inheritance, implement additional interfaces via method delegation
- Consider using %Dictionary classes for runtime interface discovery
- Legacy code adaptation often involves global variable access patterns
