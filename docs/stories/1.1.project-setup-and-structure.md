### Relevant Architecture Information

#### Tech Stack Requirements
[Source: architecture/tech-stack.md]
- **Primary Language**: InterSystems ObjectScript (Compatible with IRIS 2023.1+)
- **Testing Framework**: %UnitTest (Built-in IRIS testing framework)
- **Version Control**: Git with GitHub, using Git Flow branching (main, develop, feature/*, release/*)
- **IDE**: VS Code with ObjectScript Extension (primary), InterSystems Studio (optional)
- **Docker** (Optional): Using intersystemsdc/iris-community:latest image
- **Package Registry**: InterSystems Package Manager Registry for public distribution

#### Source Tree Structure
[Source: architecture/source-tree.md]
The repository must follow this exact directory structure:
- `/src/Patterns/GoF/[Creational|Structural|Behavioral]/` - GoF pattern implementations
- `/src/Patterns/PoEAA/[DataSource|DomainLogic|etc.]/` - PoEAA pattern implementations
- `/src/Patterns/Registry/` - Contains Manager.cls, PatternInfo.cls, Loader.cls
- `/src/Patterns/Utils/` - Contains Logger.cls, Validator.cls, Performance.cls, Documentation.cls
- `/src/Patterns/Examples/` - Contains Person.cls, Address.cls, Order.cls, OrderItem.cls, Demo.cls
- `/src/includes/` - Contains PatternMacros.inc and ErrorCodes.inc
- `/tests/Unit/`, `/tests/Integration/`, `/tests/Performance/`, `/tests/Fixtures/` - Test structure
- `/examples/basic/`, `/examples/advanced/`, `/examples/real-world/` - Example code
- `/docs/` - All documentation
- `/scripts/` - Build and deployment scripts (install.sh, build.sh, test.sh, deploy.sh)
- `/docker/` - Docker configuration files
- `/.vscode/` - VS Code configuration
- `/.github/` - GitHub workflows and templates

#### File Naming Conventions
[Source: architecture/source-tree.md]
- ObjectScript Classes: PascalCase with .cls extension
- Include Files: PascalCase with .inc extension  
- Documentation: kebab-case with .md extension
- Scripts: kebab-case with appropriate extension
- Configuration: lowercase with standard extensions

#### Coding Standards References
[Source: architecture/coding-standards.md]
- Must follow comprehensive standards in "Object Script Coding Standards.md" document
- Class naming: PascalCase with namespace prefix (e.g., Patterns.GoF.Creational.Singleton)
- All code must be compatible with IRIS 2023.1+
- No external dependencies outside IRIS platform
- Pure ObjectScript implementation only (no embedded Java/Python)

### Testing
[Source: architecture/test-strategy.md]
#### Test Namespace Configuration
- Test namespace: PATTERNS-TEST (separate from main PATTERNS namespace)
- Test framework: %UnitTest (built-in IRIS testing framework)
- Test organization must mirror source structure under /tests/ directory
- Base test class: Patterns.Test.TestCase extends %UnitTest.TestCase
