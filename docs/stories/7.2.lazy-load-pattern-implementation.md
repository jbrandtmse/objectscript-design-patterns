### Lazy Load Pattern Specific Considerations

- **Virtual Proxy**: Proxy object stands in for real object, loads on first method call
- **Ghost Object**: Real object with uninitialized state, loads on first property access
- **Value Holder**: Wrapper holds value, computes/loads on demand
- **Transparent Loading**: Loading happens automatically without client knowledge
- **Load State Tracking**: Track whether object/value has been loaded
- **Performance**: Defer expensive operations until actually needed
- **Collections**: Lazy load one-to-many relationships
- **Circular References**: Handle carefully to avoid infinite loops
- **Integration**: Works with Identity Map and Data Mapper

### Lazy Load Implementation Patterns

[Source: architecture/coding-standards.md]

**Virtual Proxy Pattern:**
```objectscript
Class VirtualProxyPatient Extends %RegisteredObject
{
    Property PatientId As %String;
    Property %MedicalHistory As %ListOfObjects [ Private ];
    Property %IsHistoryLoaded As %Boolean [ Private ];
    
    Method GetMedicalHistory() As %ListOfObjects
    {
        // Lazy load on first access
        If '..%IsHistoryLoaded {
            Do ..LoadMedicalHistory()
        }
        
        Quit ..%MedicalHistory
    }
    
    Method LoadMedicalHistory() As %Status [ Private ]
    {
        Set tSC = $$$OK
        
        // Load medical history from database
        Set ..%MedicalHistory = ##class(MedicalHistoryMapper).FindByPatientId(..PatientId)
        Set ..%IsHistoryLoaded = 1
        
        Quit tSC
    }
}
```

**Ghost Object Pattern:**
```objectscript
Class GhostPatient Extends %RegisteredObject
{
    Property PatientId As %String;
    Property FirstName As %String;
    Property %IsLoaded As %Boolean [ Private ];
    
    Method FirstNameGet() As %String
    {
        // Load on first property access
        If '..%IsLoaded {
            Do ..Load()
        }
        
        Quit i%FirstName
    }
    
    Method Load() As %Status [ Private ]
    {
        // Load all properties from database
        Set tData = ##class(PatientMapper).Load(..PatientId)
        Set i%FirstName = tData.FirstName
        // ... load other properties
        Set ..%IsLoaded = 1
        
        Quit $$$OK
    }
}
```

**Value Holder Pattern:**
```objectscript
Class ValueHolder Extends %RegisteredObject
{
    Property %Value As %RegisteredObject [ Private ];
    Property %IsLoaded As %Boolean [ Private ];
    Property %Loader As %String [ Private ];
    Property %LoaderId As %String [ Private ];
    
    Method GetValue() As %RegisteredObject
    {
        If '..%IsLoaded {
            Do ..Load()
        }
        
        Quit ..%Value
    }
    
    Method Load() As %Status [ Private ]
    {
        Set ..%Value = $CLASSMETHOD(..%Loader, "Load", ..%LoaderId)
        Set ..%IsLoaded = 1
        Quit $$$OK
    }
}
```

### Healthcare Medical History Lazy Loading Requirements

- **Large Medical History**: Defer loading complete patient history until needed
- **Lab Results**: Lazy load lab results collection (could be thousands)
- **Imaging Studies**: Defer loading large imaging data until accessed
- **Medication History**: Load medication list on demand
- **Performance**: Show measurable performance improvement
- **Transparent**: Client code unaware of lazy loading mechanism
