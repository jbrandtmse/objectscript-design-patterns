### Money Implementation Patterns

[Source: architecture/coding-standards.md]

**Money Construction:**
```objectscript
Class Money Extends %RegisteredObject
{
    Property Amount As %Numeric(SCALE = 2);
    Property Currency As %String;
    
    Method %OnNew(pAmount As %Numeric, pCurrency As %String = "USD") As %Status
    {
        Set i%Amount = pAmount
        Set i%Currency = pCurrency
        Quit $$$OK
    }
}
```

**Addition with Currency Validation:**
```objectscript
Method Add(pOther As Money) As Money
{
    If (..Currency '= pOther.Currency) {
        // Throw error - cannot add different currencies
        Quit $$$NULLOREF
    }
    
    Set tNewAmount = ..Amount + pOther.Amount
    Quit ##class(Money).%New(tNewAmount, ..Currency)
}
```

**Division with Rounding:**
```objectscript
Method Divide(pDivisor As %Numeric, pRounding As %String = "HALF_UP") As Money
{
    Set tResult = ..Amount / pDivisor
    
    If (pRounding = "HALF_UP") {
        Set tRounded = $FNUMBER(tResult, "", 2)
    } ElseIf (pRounding = "HALF_EVEN") {
        // Banker's rounding
        Set tRounded = $JUSTIFY(tResult, 0, 2)
    }
    
    Quit ##class(Money).%New(tRounded, ..Currency)
}
```
