### Data Mapper Pattern Specific Considerations

- **Complete Separation**: Domain objects have ZERO database knowledge
- **Mapper Responsibility**: All SQL, persistence logic resides in mapper
- **Domain Purity**: Domain objects contain only business logic and data
- **Identity Map**: Ensures same object instance returned for same database row
- **Lazy Loading**: Support for deferred loading of related objects
- **Object Graph Mapping**: Handle complex relationships and collections
- **Insert/Update/Delete**: Mapper methods operate on domain objects
- **Finder Methods**: Class methods returning fully-populated domain objects
- **No %Persistent**: Domain objects do NOT extend %Persistent
- **Transaction Coordination**: Mappers participate in unit of work pattern

### Data Mapper vs Other Patterns

- **Data Mapper vs Active Record**: Mapper separates completely; Active Record combines logic with persistence
- **Data Mapper vs Row Data Gateway**: Mapper works with rich domain objects; Row Gateway wraps database rows
- **Data Mapper vs Table Data Gateway**: Mapper creates domain objects; Table Gateway returns data structures
- **When to use Data Mapper**: Complex domain models, rich business logic, need clean separation
- **When NOT to use**: Simple CRUD (use Active Record), table-oriented operations (use Table Gateway), row-centric needs (use Row Gateway)

### Identity Map Pattern Integration

[Source: Previous PoEAA patterns]
- **Purpose**: Ensure same object instance for same database row
- **Implementation**: Dictionary/hash map keyed by ID
- **Lookup**: Check map before database query
- **Storage**: Store domain object reference in map after load
- **Cleanup**: Clear map at transaction boundaries
- **Concurrency**: Handle thread-safe access if needed

### Data Mapper Implementation Patterns

[Source: architecture/coding-standards.md]

**Insert Pattern:**
```objectscript
Method Insert(pDomainObject As ClinicalEncounter) As %Status
{
    Set tSC = $$$OK
    
    Try {
        // Extract data from domain object
        Set tData = ..MapToDatabase(pDomainObject)
        
        // Execute INSERT
        &sql(INSERT INTO ClinicalEncounters 
             (PatientMRN, ProviderName, EncounterDate, EncounterType, ChiefComplaint, Diagnosis, TreatmentPlan)
             VALUES (:tData.PatientMRN, :tData.ProviderName, :tData.EncounterDate, 
                     :tData.EncounterType, :tData.ChiefComplaint, :tData.Diagnosis, :tData.TreatmentPlan))
        
        If (SQLCODE = 0) {
            // Set ID on domain object
            Set pDomainObject.EncounterId = %ROWID
            
            // Add to Identity Map
            Do ..AddToIdentityMap(%ROWID, pDomainObject)
        } Else {
            Set tSC = $$$ERROR($$$GeneralError, "Insert failed: " _ SQLCODE)
        }
        
    } Catch ex {
        Set tSC = ex.AsStatus()
    }
    
    Quit tSC
}
```

**Find Pattern with Identity Map:**
```objectscript
Method Find(pId As %String) As ClinicalEncounter
{
    Set tDomainObject = ""
    
    Try {
        // Check Identity Map first
        Set tDomainObject = ..GetFromIdentityMap(pId)
        If $IsObject(tDomainObject) {
            Quit
        }
        
        // Load from database
        &sql(SELECT PatientMRN, ProviderName, EncounterDate, EncounterType, 
                    ChiefComplaint, Diagnosis, TreatmentPlan
             INTO :tMRN, :tProvider, :tDate, :tType, :tComplaint, :tDiagnosis, :tPlan
             FROM ClinicalEncounters
             WHERE ID = :pId)
        
        If (SQLCODE = 0) {
            // Create domain object
            Set tDomainObject = ##class(ClinicalEncounter).%New()
            Set tDomainObject.EncounterId = pId
            Set tDomainObject.PatientMRN = tMRN
            Set tDomainObject.ProviderName = tProvider
            // ... set remaining properties
            
            // Add to Identity Map
            Do ..AddToIdentityMap(pId, tDomainObject)
        }
        
    } Catch ex {
        // Log error
    }
    
    Quit tDomainObject
}
```

**MapToDomain Pattern:**
```objectscript
Method MapToDomain(pId As %String, pData As %DynamicObject) As ClinicalEncounter
{
    Set tDomain = ##class(ClinicalEncounter).%New()
    
    Set tDomain.EncounterId = pId
    Set tDomain.PatientMRN = pData.PatientMRN
    Set tDomain.ProviderName = pData.ProviderName
    Set tDomain.EncounterDate = pData.EncounterDate
    Set tDomain.EncounterType = pData.EncounterType
    Set tDomain.ChiefComplaint = pData.ChiefComplaint
    Set tDomain.Diagnosis = pData.Diagnosis
    Set tDomain.TreatmentPlan = pData.TreatmentPlan
    
    Quit tDomain
}
```

### Healthcare Clinical Encounter Domain Requirements

- **Pure Domain Class**: ClinicalEncounter extends %RegisteredObject (NOT %Persistent)
- **Domain Properties**: EncounterId, PatientMRN, ProviderName, EncounterDate, EncounterType, ChiefComplaint, Diagnosis, TreatmentPlan
- **Business Logic**: Methods for clinical workflow (ValidateEncounter(), CalculateBillingCodes(), etc.)
- **No Database Code**: Zero SQL, zero persistence code in domain class
- **Value Objects**: Consider using value objects for complex types (Address, Diagnosis)
- **Mapper Handles Persistence**: ClinicalEncounterMapper handles all database operations

### SQL Injection Prevention

[Source: architecture/coding-standards.md]
- **ALWAYS use parameterized queries** with :param placeholders
- **NEVER concatenate user input into SQL strings**
- Use embedded SQL &sql() with :paramName syntax
- Validate and sanitize input before SQL execution
- Log all SQL execution failures for security auditing

### Error Handling Requirements

[Source: architecture/coding-standards.md]
- Return %Status from all methods that can fail
- Use $$$OK and $$$ERROR macros
- Implement proper Try/Catch blocks
- Provide meaningful error messages with context
- **CRITICAL**: Cannot use argumented QUIT within Try/Catch blocks
  - Initialize return variable before Try
  - Set return value within Try
  - Use argumentless QUIT in Try/Catch
  - Return variable after Try/Catch block
- Check SQLCODE after every SQL operation
