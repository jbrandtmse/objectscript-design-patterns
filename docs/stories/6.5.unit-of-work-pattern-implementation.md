### Unit of Work Pattern Specific Considerations

- **Change Tracking**: Maintain lists of new, dirty, and deleted objects
- **Transaction Coordination**: Execute all operations within single database transaction
- **Batch Updates**: Optimize by batching database operations
- **Dependency Ordering**: Insert new objects first, then update, then delete
- **Atomicity**: All operations succeed or all fail (rollback)
- **Integration with Mappers**: Use Data Mapper pattern for actual persistence
- **Clean State Management**: Track which objects are unchanged
- **Validation**: Check business rules before committing changes
- **Audit Trail**: Log all changes for compliance and debugging

### Unit of Work Implementation Patterns

[Source: architecture/coding-standards.md]

**RegisterNew Pattern:**
```objectscript
Method RegisterNew(pObject As %RegisteredObject) As %Status
{
    Set tSC = $$$OK
    
    Try {
        // Check if already registered
        If ..IsRegistered(pObject) {
            Quit
        }
        
        // Add to new objects collection
        Do ..NewObjects.Insert(pObject)
        
    } Catch ex {
        Set tSC = ex.AsStatus()
    }
    
    Quit tSC
}
```

**Commit Pattern:**
```objectscript
Method Commit() As %Status
{
    Set tSC = $$$OK
    
    Try {
        // Start transaction
        TSTART
        
        // 1. Insert new objects first
        Set tIterator = ..NewObjects.%GetIterator()
        While tIterator.%GetNext(.key, .object) {
            Set tSC = ..GetMapper(object).Insert(object)
            If $$$ISERR(tSC) {
                TROLLBACK
                Quit
            }
        }
        
        // 2. Update dirty objects
        Set tIterator = ..DirtyObjects.%GetIterator()
        While tIterator.%GetNext(.key, .object) {
            Set tSC = ..GetMapper(object).Update(object)
            If $$$ISERR(tSC) {
                TROLLBACK
                Quit
            }
        }
        
        // 3. Delete removed objects last
        Set tIterator = ..DeletedObjects.%GetIterator()
        While tIterator.%GetNext(.key, .object) {
            Set tSC = ..GetMapper(object).Delete(object)
            If $$$ISERR(tSC) {
                TROLLBACK
                Quit
            }
        }
        
        // Commit transaction
        TCOMMIT
        
        // Clear tracking collections
        Do ..Clear()
        
    } Catch ex {
        TROLLBACK
        Set tSC = ex.AsStatus()
    }
    
    Quit tSC
}
```

**Rollback Pattern:**
```objectscript
Method Rollback() As %Status
{
    Set tSC = $$$OK
    
    Try {
        // Clear all tracking collections
        Do ..NewObjects.Clear()
        Do ..DirtyObjects.Clear()
        Do ..DeletedObjects.Clear()
        
        // Rollback any active transaction
        TROLLBACK
        
    } Catch ex {
        Set tSC = ex.AsStatus()
    }
    
    Quit tSC
}
```
