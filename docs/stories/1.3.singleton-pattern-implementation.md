### Class Structure Template
[Source: architecture/coding-standards.md]
```objectscript
/// Gang of Four Singleton Pattern Implementation
/// 
/// Intent:
/// Ensure a class has only one instance and provide a global point of access to it.
/// 
/// Applicability:
/// - There must be exactly one instance of a class
/// - The instance must be accessible from a well-known access point
/// 
/// Structure:
/// <example>
/// Set singleton = ##class(Patterns.GoF.Creational.Singleton).GetInstance()
/// </example>
/// 
/// @see Patterns.GoF.Creational.Factory
/// @since 1.0.0
Class Patterns.GoF.Creational.Singleton Extends %RegisteredObject
{
    // ===== PARAMETERS =====
    Parameter VERSION = "1.0.0";
    Parameter PATTERN_TYPE = "Creational";
    
    // ===== PROPERTIES =====
    /// Private instance holder
    Property %Instance As Singleton [ Private, ClassMethod ];
    
    // ===== CONSTRUCTORS/DESTRUCTORS =====
    /// Private constructor to prevent direct instantiation
    Method %OnNew() As %Status [ Private ]
    {
        // Initialization logic
        Return $$$OK
    }
    
    // ===== CLASS METHODS =====
    /// Get the singleton instance
    ClassMethod GetInstance() As Singleton
    {
        // Thread-safe implementation with double-checked locking
    }
}
```

### Naming Conventions
[Source: architecture/coding-standards.md]
- Parameters prefix: 'p' (e.g., pTimeout, pLockName)
- Local variables prefix: 't' (e.g., tInstance, tStatus)
- Properties: PascalCase (e.g., ConfigValue, IsInitialized)
- Private properties/methods: prefix with '%'
- Lock globals: ^Patterns.Lock("ClassName")

### Thread Safety Requirements
[Source: architecture/coding-standards.md - Performance Guidelines]
The Singleton must use IRIS locking mechanisms for thread safety:
```objectscript
// Use $LOCK for exclusive access
Lock +^Patterns.Lock("Singleton"):5
If '$TEST {
    // Handle timeout
}
// Critical section
Lock -^Patterns.Lock("Singleton")
```
