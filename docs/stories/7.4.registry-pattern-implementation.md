### Registry Pattern Specific Considerations

- **Global Access**: Provide well-known object access point
- **Singleton Instance**: Registry itself is typically singleton
- **Thread Safety**: Implement locking for concurrent access
- **Scoped Registries**: Support application, session, request scopes
- **Well-Known Services**: Common pattern for service location
- **Initialization**: Clear strategy for populating registry
- **Testing**: Consider registry state between tests
- **Anti-Pattern Warning**: Global state can hinder testability

### Registry Implementation Patterns

[Source: architecture/coding-standards.md]

**Singleton Registry Pattern:**
```objectscript
Class Registry Extends %RegisteredObject
{
    Property Entries [ MultiDimensional ];
    
    ClassMethod GetInstance() As Registry
    {
        If '$Data(^Registry.Instance) {
            Set ^Registry.Instance = ..%New()
        }
        Quit ^Registry.Instance
    }
    
    Method Set(pKey As %String, pValue As %RegisteredObject) As %Status
    {
        Set tSC = $$$OK
        
        Try {
            // Thread-safe storage
            Lock +^Registry.Entries(pKey)
            Set ..Entries(pKey) = pValue
            Lock -^Registry.Entries(pKey)
            
        } Catch ex {
            Set tSC = ex.AsStatus()
        }
        
        Quit tSC
    }
    
    Method Get(pKey As %String) As %RegisteredObject
    {
        Set tValue = ""
        
        If $Data(..Entries(pKey)) {
            Set tValue = ..Entries(pKey)
        }
        
        Quit tValue
    }
}
```

**Service Registry Pattern:**
```objectscript
Class HealthcareServiceRegistry Extends Registry
{
    ClassMethod Initialize() As %Status
    {
        Set tSC = $$$OK
        Set tRegistry = ..GetInstance()
        
        // Register well-known services
        Do tRegistry.Set("PatientService", ##class(PatientService).%New())
        Do tRegistry.Set("EncounterService", ##class(EncounterService).%New())
        Do tRegistry.Set("BillingService", ##class(BillingService).%New())
        
        Quit tSC
    }
    
    ClassMethod GetPatientService() As PatientService
    {
        Quit ..GetInstance().Get("PatientService")
    }
}
```
