### Registry Implementation Patterns

[Source: architecture/coding-standards.md]

**Singleton Registry Pattern:**
```objectscript
Class Registry Extends %RegisteredObject
{
    Property Entries [ MultiDimensional ];
    
    ClassMethod GetInstance() As Registry
    {
        If '$Data(^Registry.Instance) {
            Set ^Registry.Instance = ..%New()
        }
        Quit ^Registry.Instance
    }
    
    Method Set(pKey As %String, pValue As %RegisteredObject) As %Status
    {
        Set tSC = $$$OK
        
        Try {
            // Thread-safe storage
            Lock +^Registry.Entries(pKey)
            Set ..Entries(pKey) = pValue
            Lock -^Registry.Entries(pKey)
            
        } Catch ex {
            Set tSC = ex.AsStatus()
        }
        
        Quit tSC
    }
    
    Method Get(pKey As %String) As %RegisteredObject
    {
        Set tValue = ""
        
        If $Data(..Entries(pKey)) {
            Set tValue = ..Entries(pKey)
        }
        
        Quit tValue
    }
}
```

**Service Registry Pattern:**
```objectscript
Class HealthcareServiceRegistry Extends Registry
{
    ClassMethod Initialize() As %Status
    {
        Set tSC = $$$OK
        Set tRegistry = ..GetInstance()
        
        // Register well-known services
        Do tRegistry.Set("PatientService", ##class(PatientService).%New())
        Do tRegistry.Set("EncounterService", ##class(EncounterService).%New())
        Do tRegistry.Set("BillingService", ##class(BillingService).%New())
        
        Quit tSC
    }
    
    ClassMethod GetPatientService() As PatientService
    {
        Quit ..GetInstance().Get("PatientService")
    }
}
```

### Completion Notes
- **Final Implementation**: Registry pattern using %Persistent base class with database persistence
- **Architecture**: Singleton pattern using %OpenId() to retrieve persisted instance with "Global" scope as IdKey
- **Storage**: Instance multidimensional property (RegistryData) preserves object references across saves/loads
- **Healthcare Example**: HealthcareServiceRegistry with 4 well-known services (PatientService, EncounterService, BillingService, NotificationService)
- **Test Results**: 20/20 unit tests passing (100% success rate)
- **Design Evolution**: Changed from %RegisteredObject to %Persistent after discovering ObjectScript serializes objects in globals (permanent or PPG)
- **Key Implementation Details**:
  - Registry extends %Persistent with Scope property as IdKey
  - GetInstance() uses %OpenId("Global") for true singleton behavior
  - Set() method stores objects in instance property and conditionally saves
  - HealthcareServiceRegistry auto-initializes services on first access
  - All convenience methods (GetPatientService(), etc.) work correctly
- **Production Ready**: Pattern fully tested and ready for use in healthcare service location scenarios
