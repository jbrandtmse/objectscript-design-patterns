### Repository Pattern Specific Considerations

- **Collection Interface**: Repository provides collection-like abstraction over data access
- **Domain Objects**: Works with rich domain objects, not data structures
- **Specification Pattern**: Use specifications for flexible query criteria
- **Persistence Agnostic**: Repository hides persistence implementation
- **Integration**: Uses Data Mapper for persistence, Identity Map for caching
- **Domain-Driven Design**: Central to DDD tactical patterns
- **Encapsulation**: Encapsulates complex queries and data access logic
- **Repository vs DAO**: Repository is collection-oriented, DAO is data-oriented

### Repository Implementation Patterns

[Source: architecture/coding-standards.md]

**Add Pattern:**
```objectscript
Method Add(pEntity As %RegisteredObject) As %Status
{
    Set tSC = $$$OK
    
    Try {
        // Use mapper to persist
        Set tSC = ..Mapper.Insert(pEntity)
        If $$$ISERR(tSC) {
            Quit
        }
        
        // Add to identity map
        Do ..IdentityMap.Add(pEntity.GetId(), pEntity)
        
    } Catch ex {
        Set tSC = ex.AsStatus()
    }
    
    Quit tSC
}
```

**FindBySpecification Pattern:**
```objectscript
Method FindBySpecification(pSpec As Specification) As %ListOfObjects
{
    Set tList = ##class(%ListOfObjects).%New()
    
    Try {
        // Get SQL from specification
        Set tSQL = pSpec.ToSQL()
        
        // Execute query
        Set tStatement = ##class(%SQL.Statement).%New()
        Set tSC = tStatement.%Prepare(tSQL)
        
        If $$$ISOK(tSC) {
            Set tResult = tStatement.%Execute()
            
            While tResult.%Next() {
                Set tId = tResult.%Get("ID")
                
                // Check identity map first
                Set tEntity = ..IdentityMap.Get(tId)
                
                If '$IsObject(tEntity) {
                    // Load from mapper
                    Set tEntity = ..Mapper.Find(tId)
                    Do ..IdentityMap.Add(tId, tEntity)
                }
                
                Do tList.Insert(tEntity)
            }
        }
        
    } Catch ex {
        // Log error
    }
    
    Quit tList
}
```

**Specification Pattern:**
```objectscript
Class PatientByDepartmentSpec Extends Specification
{
    Property Department As %String;
    
    Method ToSQL() As %String
    {
        Set tSQL = "SELECT ID FROM Patients WHERE Department = ?"
        Set tSQL = tSQL _ " /* Parameters: " _ ..Department _ " */"
        Quit tSQL
    }
    
    Method GetParameters() As %ListOfDataTypes
    {
        Set tParams = ##class(%ListOfDataTypes).%New()
        Do tParams.Insert(..Department)
        Quit tParams
    }
}
```

### Healthcare Patient Repository Requirements

- **Domain-Focused**: Work with Patient domain objects, not data structures
- **Collection Interface**: Add(), Remove(), FindById(), FindAll()
- **Healthcare Finders**: FindByMRN(), FindActivePatients(), FindByDepartment()
- **Specifications**: PatientByStatusSpec, PatientByDepartmentSpec, ActivePatientSpec
- **Combined Queries**: Support AND/OR specifications for complex queries
- **Persistence Hidden**: Domain code unaware of underlying database
