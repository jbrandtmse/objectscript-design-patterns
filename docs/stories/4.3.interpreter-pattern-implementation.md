### Class Structure Template for Interpreter Pattern
[Source: architecture/coding-standards.md]
```objectscript
/// Gang of Four Interpreter Pattern - Language Interpretation
Class Patterns.GoF.Behavioral.Expression Extends %RegisteredObject
{
    /// Interpret the expression in the given context
    Method Interpret(pContext As Context) As %String [ Abstract ]
    {
        Quit ""
    }
    
    /// Get string representation of expression
    Method ToString() As %String [ Abstract ]
    {
        Quit ""
    }
}

/// Context for variable storage and state
Class Patterns.GoF.Behavioral.Context Extends %RegisteredObject
{
    /// Variable storage
    Property Variables As %DynamicObject;
    
    /// Get variable value
    Method GetVariable(pName As %String) As %String
    {
        If ..Variables.%IsDefined(pName) {
            Quit ..Variables.%Get(pName)
        }
        Quit ""
    }
    
    /// Set variable value
    Method SetVariable(pName As %String, pValue As %String) As %Status
    {
        Do ..Variables.%Set(pName, pValue)
        Quit $$$OK
    }
}
```

### Interpreter Pattern Specific Considerations
- **Grammar Definition**: Use BNF notation for expression grammar
- **Parser Strategy**: Recursive descent parser for simplicity
- **Context Management**: Shared context for variable state
- **Expression Trees**: Composite pattern for tree structure
- **Type System**: Support numeric, boolean, and string types
- **Error Handling**: Graceful handling of parse and evaluation errors
- **Performance**: Cache compiled expressions when possible
- **Memory Management**: Avoid deep recursion in complex expressions

### Healthcare Clinical Rule Requirements
- **Rule Types**: Lab value checks, medication interactions, clinical alerts
- **Operators**: Comparison (>, <, =), logical (AND, OR, NOT), temporal (WITHIN, BEFORE, AFTER)
- **Context Data**: Patient demographics, lab results, medications, diagnoses
- **Rule Priority**: Support for rule ordering and conflict resolution
- **Temporal Logic**: Time-based expressions for trending and sequences
- **Unit Support**: Handle medical units (mg/dL, mmol/L, etc.)
- **Alert Levels**: Info, Warning, Critical classifications
- **Audit Trail**: Log all rule evaluations for compliance

### DSL Building in ObjectScript
[Source: architecture/coding-standards.md]
- **Method Chaining**: Use $THIS for fluent interfaces
- **Operator Overloading**: Not available - use named methods
- **Macro Support**: Use ObjectScript macros for DSL shortcuts
- **Dynamic Dispatch**: Use $METHOD and $CLASSMETHOD for flexibility
- **String Parsing**: Use $PIECE, $FIND, $EXTRACT for tokenization
- **Regular Expressions**: Use %Regex.Matcher for pattern matching
- **Code Generation**: Generate ObjectScript code from DSL
- **Performance**: Pre-compile expressions where possible
