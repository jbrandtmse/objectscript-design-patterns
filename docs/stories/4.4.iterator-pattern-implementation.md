### Class Structure Template for Iterator Pattern
[Source: architecture/coding-standards.md]
```objectscript
/// Gang of Four Iterator Pattern - Sequential Access
Class Patterns.GoF.Behavioral.Iterator Extends %RegisteredObject
{
    /// Check if more elements exist
    Method HasNext() As %Boolean [ Abstract ]
    {
        Quit 0
    }
    
    /// Get next element in iteration
    Method Next() As %RegisteredObject [ Abstract ]
    {
        Quit $$$NULLOREF
    }
    
    /// Reset iterator to beginning
    Method Reset() As %Status
    {
        Quit $$$OK
    }
    
    /// Remove current element (optional operation)
    Method Remove() As %Status
    {
        Quit $$$ERROR($$$GeneralError, "Remove not supported")
    }
}

/// Iterable collection interface
Class Patterns.GoF.Behavioral.IterableCollection Extends %RegisteredObject
{
    /// Create iterator for this collection
    Method CreateIterator() As Iterator [ Abstract ]
    {
        Quit $$$NULLOREF
    }
}
```

### Iterator Pattern Specific Considerations
- **Collection Types**: Support %ListOf*, %ArrayOf*, globals, MD arrays, %DynamicObject
- **Traversal Order**: Forward, backward, depth-first, breadth-first
- **Concurrent Modification**: Detect and handle collection changes during iteration
- **Performance**: Use $ORDER for globals, minimize object creation
- **Memory Management**: Avoid loading entire collections, use lazy evaluation
- **SQL Integration**: Leverage IRIS SQL cursors for database iteration
- **Filtering**: Support predicate-based filtering during iteration
- **State Management**: Maintain iteration state without exposing internals

### ObjectScript-Specific Iteration Features
[Source: architecture/coding-standards.md]
- **$ORDER Function**: Efficient global traversal
  ```objectscript
  Set key = ""
  For {
      Set key = $ORDER(^Global(key))
      Quit:key=""
      // Process ^Global(key)
  }
  ```
- **%Iterator Interface**: Built-in iterator support for dynamic objects
- **SQL Cursors**: DECLARE, OPEN, FETCH, CLOSE cursor operations
- **Embedded SQL**: Direct SQL iteration in ObjectScript
- **Collection Classes**: Native %Collection.AbstractIterator
- **For-Each Pattern**: Not available - use manual iteration

### Global Iterator Implementation Notes
